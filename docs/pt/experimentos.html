🧪 Experimentos

Desafiante de regressão vs. o campeão heurístico ATR: uma comparação pareada offline, não um teste A/B randomizado
⚠️ Experimental. Não usado para nenhuma decisão real. O desafiante prevê um alvo contínuo de retorno/preço: todos os outros modelos deste projeto só preveem direção. Veja "Como este experimento funciona" abaixo para entender o que está (e o que não está) sendo testado aqui.
Previsões de hoje
Retorno % do desafiante e preço-alvo (EUR) com intervalo de 90% · "campeão" = a heurística ATR existente, para comparação.
Significância ao vivo (Diebold-Mariano, erro quadrático pareado)
Backtest histórico (leitura D+1, janela expansiva de 2 anos)
Baseline "naive" = prever retorno zero (uma aproximação simplificada do campeão nesta leitura retrospectiva, não a heurística ATR exata). R² > 0 significa que o modelo supera o baseline naive.
Como este experimento funciona

Isto não é um experimento controlado online no sentido clássico de teste A/B (Kohavi/Tang/Xu, Trustworthy Online Controlled Experiments): não há uma população de usuários dividida aleatoriamente entre variantes. O campeão e o desafiante avaliam o mesmo ativo, mesmo dia, mesmas condições de mercado: uma comparação pareada offline, mais próxima de um desenho matched-pairs. "Campeão vs. desafiante" é o termo correto de avaliação de ML; "teste A/B" é usado só informalmente, nunca como equivalência literal.

O que de fato se mantém é a disciplina estatística:

OEC Teste Diebold-Mariano sobre erro de previsão quadrático pareado, fixado antes de olhar os resultados.
Sem espiar N ≥ 100 previsões validadas exigidas por horizonte antes de qualquer veredito ser mostrado.
Guardrail O MAE do desafiante não pode ser >20% pior que o do campeão, mesmo se o teste principal for inconclusivo.
Lei de Twyman Um resultado inicial surpreendente (ex: um ticker com 68,8% de acurácia em n=16) é tratado como ruído até sobreviver a mais dados; regrediu para ~45% quando N cresceu.

O teste Diebold-Mariano usa h = horizonte de previsão (recomendação do próprio artigo de 1995). Janelas de previsão de múltiplos dias que se sobrepõem são serialmente correlacionadas, então D+2/D+3 precisam desse ajuste ou o teste subestima sua própria incerteza e superestima a significância.

Antes de continuar Este site é um objeto de estudo pessoal de Machine Learning aplicado a mercados financeiros. As previsões não têm significância estatística comprovada e não devem ser levadas a sério como base de decisão. Nenhuma informação aqui é conselho financeiro.
