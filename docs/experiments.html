How this experiment works

This is not an online controlled experiment in the classic A/B-testing sense (Kohavi/Tang/Xu, Trustworthy Online Controlled Experiments): there's no population of users randomly split between variants. The champion and challenger score the same asset, same day, same market conditions: a paired offline comparison, closer to a matched-pairs design. "Champion vs. challenger" is the correct ML-evaluation term; "A/B test" is only used informally, never as a literal equivalence.

What does carry over directly is the statistical discipline:

OEC Diebold-Mariano test on paired squared forecast error, fixed before looking at results.
No peeking N ≥ 100 validated predictions required per horizon before any verdict is shown.
Guardrail Challenger MAE can't be >20% worse than the champion's, even if the main test is inconclusive.
Twyman's Law A surprising early result (e.g. one ticker at 68.8% accuracy on n=16) is treated as noise until it survives more data; it regressed to ~45% once N grew.

The Diebold-Mariano test uses h = forecast horizon (1995 paper's own recommendation). Overlapping multi-day forecast windows are serially correlated, so D+2/D+3 need this adjustment or the test understates its own uncertainty and over-claims significance.

Before you go on This site is a personal study project applying Machine Learning to financial markets. The forecasts have no proven statistical significance and should not be taken seriously as a basis for decisions. Nothing here is financial advice.
